# Visual Regression Concept Model

The governance layer treats every component contract as a visual baseline. The validator prints a registry fingerprint from `component-registry.ts`.

## Strict Tolerances

- Spacing delta: 0px
- Font size delta: 0px
- Color variance: not allowed
- Layout shift from page blueprint: not allowed
- Motion duration drift: not allowed

## Future Screenshot Baselines

The next hardening step is Playwright screenshot baselines for each registered component and main page route. The current system establishes deterministic contracts and source-level token enforcement first.

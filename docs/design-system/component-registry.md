# Component Registry

Registered governed components:

- HeroSection
- DestinationMosaicGrid
- TourCard
- BookingWizard
- StickyCTA
- NavigationBar
- TestimonialCarousel
- BlogCard
- FAQAccordion

Each contract defines structure, style, motion, interaction and root obligations. The registry lives in:

```text
luxury-travel-next/design-system/component-registry.ts
```

A component without a contract is not allowed to become part of the page composition layer.

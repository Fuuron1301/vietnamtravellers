# Luxury UI Redesign Design

## Goal
Redesign only the Next.js public frontend so it keeps the Asia Pioneer-style SEO hub architecture, improves Asiatica-style tailor-made conversion, and upgrades the visual layer toward a LuxTravel DMC-inspired luxury travel aesthetic without copying protected assets.

## Reference Evidence
- LuxTravel DMC emphasizes destination mega menu, inquiry CTA, luxury tailor-made hero, duration/search strip, USP blocks, Southeast Asia positioning, popular tours, and gold-accent luxury messaging.
- Asia Pioneer provides the SEO architecture pattern: destination hub pages, tour pages, travel styles and blog content linking together.
- Asiatica Travel emphasizes a prominent 100% tailor-made CTA, destination/tour menu grouping, travel packages, reviews, and a five-step booking flow.

## Design Direction
Use a cinematic editorial style: 100vh image hero, centered serif typography, deep navy/ivory/gold palette, large image-first cards, asymmetrical destination grids, subtle shadows, line icons and restrained gold accents. Motion uses slow fade-up, staggered reveals, hover image zoom, glass header transition and sticky CTA.

## Scope
Frontend-only changes in `luxury-travel-next`: Tailwind tokens, globals, motion primitives, header, home page, hub page, tour detail, tour cards, blog index/detail and tailor-made form UI. WordPress plugin, REST API, data model and SEO routes remain intact.
